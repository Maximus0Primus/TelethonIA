## 📌 Re-audit SQL pour J+7 (2026-05-24)

```sql
-- Vérifier que les 2 picks tiennent toujours + check companion-shadow drift
WITH bl AS (
  SELECT (jsonb_path_query_array(paper_trade_config, '$.kol_chain_blacklist.solana[*]'))::text[]::text[] AS sol_bl
  FROM scoring_config ORDER BY updated_at DESC LIMIT 1
),
dedup AS (
  SELECT DISTINCT ON (strategy, token_address, DATE(created_at))
    strategy, created_at, pnl_pct, pnl_usd
  FROM paper_trades, bl
  WHERE chain = 'solana' AND is_shadow = true AND source = 'rt'
    AND strategy IN ('TP50_SL40_S35','FAST_TP50_SL30_MCAP_S40')
    AND status IN ('tp_hit','sl_hit','timeout','trail_stop','be_stop')
    AND created_at >= NOW() - INTERVAL '30 days'
    AND NOT (kol_group = ANY(bl.sol_bl))
  ORDER BY strategy, token_address, DATE(created_at), created_at
)
SELECT
  strategy,
  COUNT(*) AS n_30d,
  ROUND(SUM(pnl_usd)::numeric / 30, 1) AS "30d",
  ROUND(SUM(pnl_usd) FILTER (WHERE created_at >= NOW() - INTERVAL '30 days' AND created_at < NOW() - INTERVAL '14 days')::numeric / 16, 1) AS "30→14d",
  ROUND(SUM(pnl_usd) FILTER (WHERE created_at >= NOW() - INTERVAL '14 days')::numeric / 14, 1) AS "14d",
  ROUND(SUM(pnl_usd) FILTER (WHERE created_at >= NOW() - INTERVAL '7 days')::numeric / 7, 1) AS "7d",
  ROUND(SUM(pnl_usd) FILTER (WHERE created_at >= NOW() - INTERVAL '5 days')::numeric / 5, 1) AS "5d",
  ROUND((100 * percentile_cont(0.5) WITHIN GROUP (ORDER BY pnl_pct)
        FILTER (WHERE created_at >= NOW() - INTERVAL '14 days'))::numeric, 1) AS "med14"
FROM dedup
GROUP BY strategy
ORDER BY "7d" DESC;
```

**Critères go/no-go pour scale live au-delà de $0.50** :
- TOUTES les 4 fenêtres (30→14d, 14d, 7d, 5d) ≥ $10/d
- med14 ≥ 0
- N_30d ≥ 200
- Drift live↔paper main < 10pp (mesuré sur pilot Phase 3)

Si UN critère ❌ → reste en paper main + pilot, ne PAS scale.
